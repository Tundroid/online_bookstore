INSTRUCTIONS
1. Each student will present their project in 3 minutes.
2. Your written report must not exceed 30 pages.

4. Code must be your own work; plagiarism results in zero.
PROJECT BRIEF
Project Title: Online Bookstore Web Application
You are required to design and develop a fully functional online bookstore where users can browse,
search, and purchase books. The system must integrate HTML, CSS, and Bootstrap for the front-end
interface, JavaScript for dynamic client-side behaviour, and PHP with MySQL for server-side
processing and persistent data management.
REQUIRED FEATURES
1. User Authentication [5 Marks]
› Allow new users to register with a validated sign-up form. 1 mk
› Implement secure login, logout, and session management. 2 mks
› Enable users to view and edit their account/profile details. 2 mks
2. Book Catalog Page [5 Marks]
› Display a paginated list of all available books with a clear layout. 2 mks
› Show title, author, cover image, price, and short description per entry. 2 mks
› Ensure the layout is responsive across mobile, tablet, and desktop screens. 1 mk
3. Search Functionality [5 Marks]
› Implement keyword search by book title. 2 mks
› Extend search to filter by author name or genre category. 2 mks
› Provide clear UI feedback (loading state, empty results message). 1 mk
4. Book Details Page [5 Marks]
› Display full book information: description, author, publisher, and price. 2 mks
› Include a functional 'Add to Cart' button linked to the cart system. 2 mks
› Ensure a clean, intuitive UI/UX for the detail view. 1 mk
5. Shopping Cart System [10 Marks]
› Allow authenticated users to add books to their cart. 3 mks
› Enable viewing, updating quantities, and removing cart items. 4 mks
› Dynamically reflect quantity changes in the running total. 2 mks
› Maintain cart state across the session (bonus: persistent cart). 1 mk
6. Checkout Process [5 Marks]
› Present a form to collect shipping address and payment information. 2 mks
› Store order data and display an order confirmation page. 2 mks
› Include client-side and server-side validation with error feedback. 1 mk
7. Order History [10 Marks]
› Display a chronological list of all past orders for logged-in users. 3 mks
› Show order status labels (e.g., Pending, Processing, Shipped, Delivered). 2 mks
› Include per-order details: books purchased, quantities, and order date. 3 mks
› Present orders in a clear dashboard layout with summary statistics. 2 mks
8. Admin Panel [15 Marks]
› Implement full CRUD operations for books (Create, Read, Update, Delete). 5 mks
› Provide sales reports filterable by book title, date range, or customer. 4 mks
› Restrict panel access to admin accounts via secure authentication check. 3 mks
› Design a clear, well-organised UI for all admin management functions. 3 mks
9. Documentation [10 Marks]
› Write a project overview explaining the system goals and scope. 1 mk
› Include a database schema diagram (ERD) covering all tables and relations. 2 mks
› Describe the backend architecture and front-end component structure. 2 mks
› Provide clear deployment/setup instructions for local and server environments. 2 mks
› Include a user manual with annotated screenshots illustrating key workflows. 3 mks
